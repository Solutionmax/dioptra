# Brand assets

Dioptra is created by SolutionMAX.

- `src/brand/dioptra.png`: 256×256 Twin View app mark, used in the browser and About panel.
- `build/icon.png` and `build/dioptra-mark.png`: 1024×1024 versions of the same Twin View mark. Electron-builder converts `icon.png` to platform app and installer icons. The drawing and transparency are preserved.
- `src/brand/solutionmax.png`: SolutionMAX emblem from the company brand pack (2026-10-05), trimmed to its content and scaled to 256 px.
- `build/solutionmax.svg`: existing SolutionMAX vector logo from the company's local video/brand assets.
- `src/brand/claude.png`: original Anthropic Claude extension icon; identifies the Claude integration.
